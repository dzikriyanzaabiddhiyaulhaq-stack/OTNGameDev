# 404: Title Not Found
***A Short Game Where You Work As a Python Developer.***
*2026 OTN Submission.*

⚠️ **COMPILED GAME NOT INCLUDED. YOU NEED TO COMPILE IT YOURSELF.**

# Description
**404: Title Not Found** is an educational coding simulation where players take on contracts from clients, learn Python, and solve coding tasks through a retro desktop interface.

# Minimum System Requirements
- x86-64 compatible CPU
- 1GB RAM
- 200MB Storage
- 512MB VRAM

# Editor Requirements
Unity Editor 6000.5.5f1
