# 404: Title Not Found
***A Short Game Where You Work As a Python Developer.***
*2026 OTN Submission.*

⚠️ **COMPILED GAME NOT INCLUDED. YOU NEED TO COMPILE IT YOURSELF.**

# Description
404: Title Not Found is a simulation game where you work as a Software Developer that receives contracts from clients.
Clients send contracts and your job is to finish those contracts by writing code, and testing it against hidden test cases.

# Minimum System Requirements
- x86-64 compatible CPU
- 1GB RAM
- 200MB Storage
- 512MB VRAM

# Editor Requirements
Unity Editor 6000.5.5f1
